# AI Task Hub

把 ChatGPT 网页、Claude Code、Codex、ZCode 和 MiniMax Code 的任务事件集中到本地桌面宠物，随时查看任务状态、事件时间线和未读消息。

## 快速开始

单进程 Windows 原生桌宠位于 `native-win32/`（基于 C++、Win32、Direct2D 与内置 SQLite）。从仓库根目录运行：

```powershell
.\native-win32\build-win32.ps1
& '.\native-win32\dist\AI Task Hub Win32.exe'
```

主程序内置本地 HTTP 服务与 SQLite。Claude Code、Codex、ZCode、MiniMax Code 的外部适配器脚本会调用系统 Python；ChatGPT 网页通过浏览器扩展上报事件。

## 桌宠交互

1. **桌面常驻与丰富待机动作**：启动后在屏幕角落显示透明背景、置顶的正常比例二次元黑丝桌宠立绘（完整包含 `idle` / `idle_blink` / `notice` / `happy` / `drag` / `walk` / `sit` / `sleep` 8 组表情动作），支持 30fps 自然呼吸起伏、随机眨眼、鼠标悬停歪头，以及自主散步（双步态交替）、坐姿阅读与时段问候、深夜/久置打盹（飘出 `Zzz`）与轻快跳跃。
2. **底部实时任务条**：桌宠脚下信息胶囊实时显示高优先级待处理任务的状态、来源、总数及标题简讯（空闲时展示服务状态或互动台词）。
3. **大小调节**：支持右键菜单「桌宠大小」（75% / 100% / 125% / 150%）或在桌宠上按住 `Ctrl` 滚动鼠标滚轮无级微调（60%~160%）并自动记忆。
4. **左键点击**：在桌宠旁弹出对话气泡式任务面板（包含收件箱、历史、详情、外观主题、平台接入与设置），再次点击或关闭按钮可收起气泡；任务状态变化或交互时会立即唤醒桌宠。
5. **直接互动（摸摸头 / 戳一戳）**：在桌宠头顶区域左右来回轻抚可触发「摸摸头」（冒出粉色爱心与开心台词）；鼠标中键轻点可「戳一戳」（吓一跳表情与星光反应）。
6. **右键菜单与物理模式**：右键可快捷跳转各页面、手动触发「摸摸头 / 戳一戳 / 小憩打盹」、开关「自由走动 / 追逐鼠标 / 重力落地（默认自由悬停）」、一键已读、开关系统通知 / 开机启动 / 深色模式、隐藏桌宠或退出。
7. **拖拽与新消息提醒**：按住桌宠拖动超过 5px 即可自由移动（带物理惯性摆动、落地回弹；开启重力落地后松手会下落并弹跳停在工作区底部）并记忆位置；收到新事件时桌宠唤醒跳跃、散发星光/光点粒子并在头顶弹出带指向尾巴的通知气泡。

各平台的接入位置：

| 平台 | 接入方式 |
| --- | --- |
| ChatGPT 网页 | 浏览器扩展上报事件（需手动加载） |
| Claude Code | `~/.claude/settings.json` 的 UserPromptSubmit / Notification / Stop 钩子 |
| Codex | `~/.codex/config.toml` 的 notify 转发 + `~/.codex/hooks.json` 提问钩子 |
| ZCode | `~/.zcode/cli/config.json` 的 `hooks.events.*` 进程钩子 |
| MiniMax Code | `<数据目录>/plugins/ai-task-hub-bridge/` 本地插件钩子 |

“已配置”只说明接入配置已写入，真实事件到达后才能确认链路可用。浏览器扩展需要手动加载。

## 数据与接入

Win32 版默认把 `data.sqlite` 放在可执行文件目录，可在设置中迁移数据目录。迁移通过 SQLite 备份复制数据，重启生效并保留旧数据库。

本地事件服务使用 `127.0.0.1:17891`。自动接入修改配置前会备份文件；复杂或损坏的配置会提示手工处理。详细行为见[原生桌宠版说明](native-win32/README.md)。

## 开发与验证

- `native-win32/`：Win32 桌宠主程序、本地服务、资源素材、单元测试与打包脚本。
- `adapters/`：各平台事件适配器与浏览器扩展。
- `shared/`：共享事件协议。
- `tests/`：适配器与源码编码回归测试（`pytest -q`）。

可先构建候选文件，再执行隔离原生测试：

```powershell
.\native-win32\build-win32.ps1 -StageOnly
.\native-win32\test-win32.ps1
```

GUI 验证需要交互式 Windows 桌面，按[原生桌宠版说明](native-win32/README.md)使用独立测试目录。
