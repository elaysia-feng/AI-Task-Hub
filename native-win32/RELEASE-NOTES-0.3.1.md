## AI Task Hub · Win32 便携版 0.3.1

本次发布继续使用独立的 `win32-v0.3.1` 标签，面向 Windows x64 原生便携版。

### 本版变化

- 新增清理菜单中的“删除已完成”，只删除 `COMPLETED_UNREAD` 消息及其事件流水。
- 清理菜单与确认框改为 Direct2D 自绘，支持 Enter 确认、Esc 取消和遮罩交互。
- 浅色模式任务卡片改为与设置页一致的半透明玻璃效果，保留壁纸可见性和文字对比度。
- 保留按来源清理、删除待处理、删除历史和删除全部任务功能。

- Win32 原生测试：69 项检查通过。
- 真实窗口清理流程验证：已完成消息数量从 1 删除为 0。
