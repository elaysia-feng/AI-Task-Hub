## AI Task Hub · Win32 便携版 0.3.2

本次发布继续使用独立的 `win32-v0.3.2` 标签，面向 Windows x64 原生便携版。

### 本版变化

- 新增神里绫华、爱弥斯和守岸人三套主题壁纸与头像预设。
- 主题选择网格按窗口宽度自适应列数，新增预设不会遮挡底部操作区。
- “恢复默认”拆分为壁纸和头像两个独立操作，恢复头像不会误清除当前壁纸。
- 选择内置主题或头像后立即刷新预览，并将选择持久化到便携版配置。
- 修正丰川祥子的显示名称，并同步 Electron、Qt/QML 与 Win32 三条桌面链路。

### 验证

- Win32 原生回归测试：71 项检查通过。
- 发布候选已完成 MinGW Release 构建；压缩包附带 SHA-256 校验文件。

下载 `AI-Task-Hub-Win32-x64-0.3.2.zip` 后完整解压运行，并核对同名 `.sha256` 文件。
