## AI Task Hub · Win32 便携版 0.3.3

本次发布使用独立的 `win32-v0.3.3` 标签，面向 Windows x64 原生便携版。

### 本版变化

- 修复设置页与工具栏 Tab 背景不透明/不可读的问题，统一 Light / Dark 两套 Tab 表面。
- 主题选择使用对应主题的 Light / Dark 壁纸预览，不再把角色头像误当作壁纸缩略图。
- 修复标题栏应用图标点击无响应，点击头像可正常打开头像选择面板。
- 保持壁纸与头像独立恢复，恢复壁纸不会清除当前头像。

### 验证

- Win32 原生回归测试：71 项检查通过。
- 已完成 MinGW Release 构建与便携包内容审计；压缩包附带 SHA-256 校验文件。

下载 `AI-Task-Hub-Win32-x64-0.3.3.zip` 后完整解压运行，并核对同名 `.sha256` 文件。
