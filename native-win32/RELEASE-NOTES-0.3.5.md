## AI Task Hub · Win32 便携版 0.3.5

本次发布使用独立的 `win32-v0.3.5` 标签，面向 Windows x64 原生便携版。

### 本版变化

- 标题栏 × 只收起为悬浮球；托盘右键“结束进程”才会退出程序。
- 新增任务完成、失败、等待输入时的应用内提醒卡片，点击可打开任务面板，5 秒自动收起。
- 保留系统托盘通知，并为 Windows 通知区域设置稳定的应用身份。
- 修复 MinGW 严格编译下 Direct2D 文本选项的枚举转换问题。
- 健康接口与状态接口版本号更新为 `0.3.5-win32`。

### 验证

- Win32 原生回归测试：71 项检查通过。
- 真实隔离进程验证：任务完成事件显示 `400×116` 提醒卡片，点击后打开 `1004×644` 任务面板。
- 发布包附带 SHA-256 校验文件。

下载 `AI-Task-Hub-Win32-x64-0.3.5.zip` 后完整解压运行，并核对同名 `.sha256` 文件。
